# コンソールメッセージ修正版

## 変更内容

継続可能なデータ条件と、実際の処理失敗を区別しました。

### 軌跡不足

従来:

```text
[error] 停止Pose除去後の軌跡点が不足しています
Traceback ...
```

修正版:

```text
[skip] 停止Poseを除くと有効な走行軌跡が不足するため、このタスクは処理対象外です
[info] バッチ処理は次のタスクへ進みます。
[skip] <clip>: ...。次のタスクへ進みます。
```

- ジョブ状態: `SKIPPED`
- 終了コード: `3`
- バッチ全体では失敗件数に含めない
- 最終状態: `COMPLETED_WITH_SKIPS`
- バッチ終了コード: `0`

### 予期しない失敗

```text
[failed] 予期しない処理失敗: ...
[info] このタスクを失敗として記録し、バッチ処理は次へ進みます。
```

通常は長いTracebackを表示しません。詳細確認時だけ、実行コマンドへ以下を追加します。

```text
--debug-traceback
```

### タスク完了

```text
[ok] <clip>: 完了 (180.25s)
```

### バッチ最終表示

```text
[summary] completed=13, skipped=1, failed=0, cancelled=0
```
